Présentation : une seule page verticale, une colonne d’étapes dans l’ordre numérique,
liaisons vers une même destination regroupées sur des collecteurs communs.
La sortie 99 du programme est affichée 9999 en bas ; son identité XML reste conservée.
Les commentaires de réseaux, les statuts SPV R4 et les messages opérateur sont associés aux étapes.
Les formats de l’ancien bloc sont réutilisés ; aucune ancienne transition ou condition n’est reprise.

Contenu analysé :
- 65 réseaux : 40 LAD et 25 SCL ;
- 34 étapes uniques ;
- 47 écritures G7.G_X_New dont le forçage global R61 ;
- 76 transitions conservées hors forçage global ;
- 31 transitions de défaut vers 999 ;
- 54 blocs écrivant des messages et 56 variantes conditionnelles, 28 SPV et 28 IHM ;
- 48 encarts après regroupement strict des textes et conditions identiques.

Les textes SCL du réseau précédent et les textes directs des CONCAT Ladder sont pris en compte.
Les variantes des étapes 50, 500 et 503 sont conservées ; les textes SPV et IHM différents restent séparés.
L’en-tête R5 (étape, Shelter/stand, type d’analyse) est représenté par des champs dynamiques,
abrégé dans l’affichage et conservé avec son expression source dans les données des formes.
Les noms de variables et expressions d’origine restent dans les données des transitions/messages.

Particularités du code :
- R50 : les conditions 500 → 501/502/503 peuvent être vraies simultanément ; aucune exclusivité n’est inventée.
- R60 : Api_Reset est une commande sous STOPPING pour les étapes concernées, et non une transition directe vers 99.
- R61 : remise à zéro sous désactivation ou absence de demande H2 avec Num_stand <> 8 et G_X > 5.
- R64/R65 : actions des résultats, commande de vanne et FinAnalyse conservées dans les données et commentaires pertinents.
- R62 : moteur Isii_G7, Front = DB_Plc.B1s et Init = DB_Plc.BIT_INIT ; son corps n’est pas fourni.

Déplacement horizontal dans Visio :
Activer le Pointeur (Ctrl+1), sélectionner le carré d’une étape, puis utiliser les flèches gauche/droite.
Les transitions, réceptivités, commentaires et messages suivent le carré ; les connexions restent collées.
Les collecteurs communs restent fixes. Les points de connexion sont disponibles sur les quatre côtés du carré.
Le suivi repose sur des formules ShapeSheet natives, sans macro et sans redistribution globale automatique.
