GRAFCET une colonne — sortie 9999 et connexions liées aux étapes

Fichier principal : Grafcet_Fct_Stands_1_colonne_9999.vsdx
Alternative éditable : Grafcet_Fct_Stands_1_colonne_9999_editable.vdx
Aperçu : Grafcet_Fct_Stands_1_colonne_9999.pdf

La sortie auparavant nommée 99 apparaît sous le numéro 9999, après l’étape de défaut 999, tout en bas de la page.
La référence 99 du XML TIA reste conservée dans les données de forme pour assurer la correspondance avec le programme.
Les commentaires visibles, le statut et l’annotation de sortie utilisent 9999.

Déplacer une étape dans Visio :
1. Activer l’outil Pointeur (Ctrl+1).
2. Sélectionner le carré de l’étape.
3. Utiliser les flèches gauche/droite ou le déplacer horizontalement.
Les transitions, leurs conditions, le commentaire et les encarts suivent horizontalement le carré.
Les connecteurs restent collés à leurs points de connexion et leurs coudes suivent le déplacement.
Les collecteurs verticaux communs restent en place et les branches conservent leur destination.
Les marques blanches des croisements suivent également les liaisons.
Les quatre côtés de chaque carré disposent de points de connexion Visio.

Le suivi est assuré par les formules natives de la feuille ShapeSheet, sans macro.
Les routes restent dans les couloirs définis ; il n’y a pas de recalcul automatique de la disposition globale.
Le déplacement horizontal est préparé ; la position verticale des composants locaux reste celle de la planche.

Microsoft Visio n’est pas installé dans cet environnement ; les vérifications de déplacement sont des évaluations indépendantes des formules ShapeSheet.
Le fonctionnement du programme TIA n’est pas modifié. La priorité des demandes reste celle du programme ; le FC Isii_G7 absent du XML n’est pas simulé.
